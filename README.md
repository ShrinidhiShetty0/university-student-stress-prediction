# University Student Stress Prediction — Deployment Starter

This Streamlit app uses the saved model and label encoder from `university_student_stress(2).ipynb`.

## Required files

Keep these files together in the project folder / GitHub repository:

- `app.py`
- `requirements.txt`
- `university_student_stress_model.pkl` (generated by your notebook)
- `stress_label_encoder.pkl` (generated by your notebook)

## 1. Create the model files in Jupyter

1. Open your notebook and make sure the cells have run successfully through the model training and evaluation.
2. Run the model-saving cell that contains `joblib.dump(...)` (cell 24 in the uploaded notebook).
3. In Jupyter, use the current notebook folder as the working directory, or run `import os; print(os.getcwd())` to find it.
4. Confirm both `.pkl` files exist in that folder. If not, copy them into the same folder as `app.py`.
5. Check your installed scikit-learn version in Jupyter with `import sklearn; print(sklearn.__version__)`. If deployment gives a scikit-learn version warning/error, pin that same version in `requirements.txt`, e.g. `scikit-learn==YOUR_VERSION`.

The uploaded notebook reads `university_student_stress_dataset.csv`. Your uploaded file has a different filename (`university_student_stress_dataset(1).csv`), so either rename a copy to `university_student_stress_dataset.csv` in the notebook folder or change the `pd.read_csv(...)` line to the actual filename.

## 2. Test locally (Windows)

Open Command Prompt in this folder and run:

```bash
py -m venv .venv
.venv\\Scripts\\activate
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

A browser tab should open with the app. Test a prediction before uploading the files to GitHub.

## 3. Deploy with Streamlit Community Cloud

1. Create/sign in to a GitHub account.
2. Create a new repository (for example, `university-student-stress-prediction`).
3. Upload `app.py`, `requirements.txt`, and both `.pkl` files. Do not upload passwords, API keys, or other secrets.
4. Open https://share.streamlit.io/ and sign in with GitHub.
5. Select **Create app**, choose the repository, branch (`main`), and main file path (`app.py`), then click **Deploy**.
6. Wait for deployment to finish, open the generated `*.streamlit.app` URL, and test the form.

Anyone with access to a public app URL may use it. Do not present its predictions as a medical diagnosis.
